# FluxDB

**FluxDB** is a high-performance, embedded ECS (Entity Component System) database designed for games and real-time applications.

## Features
- **Deterministic Replay**: Record and playback world states.
- **Spatial Pub/Sub**: Reactive queries based on physical proximity.
- **Network Delta Compression**: Optimized UDP payloads for multiplayer.
- **Microsecond Latency**: Built with O(1) spatial hashing and contiguous memory archetypes.

## Installation
Run `install.bat` (Windows) to compile and install the FluxDB engine globally.
